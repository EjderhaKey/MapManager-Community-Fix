# 漫漫长夜 MapManager 模组修复版

> 
> 针对《漫漫长夜》v2.58 版本的地图管理模组修复版本

Mod 支持官网：[https://tldmods.net/](https://tldmods.net/)
模组原作者 GitHub：[https://github.com/Arkhorse/MapManager](https://github.com/Arkhorse/MapManager)

## ✨ 特性

- 修复地图箭头显示问题 - 解决了 v2.58 版本中地图标记 / 箭头不显示的问题
- 中文语言支持 - 添加了简体中文界面
- 负重上限调整 - 添加了可调整的负重上限功能

## 📦 安装说明

1. 从 `build` 文件夹下载以下文件：
   - `MapManager.dll`
   - `MapManager.json`
2. 将这两个文件放置到游戏的模组安装目录中
3. 如有需要，根据游戏版本安装对应的 BepInEx 插件加载器

## 🧩 依赖

- BepInEx - Valheim 模组加载框架
- Valheim 游戏本体
